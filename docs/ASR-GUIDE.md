# 语音识别教程

> **English alias**: This file is the same content as [`语音识别教程.md`](./语音识别教程.md). Maintained in Chinese.

KBCut 支持在线 Whisper API 和本地 Whisper 两种方式。批量生产优先选择在线识别；没有 ASR API、素材敏感或网络不稳定时选择本地识别。

## 一、本地 Whisper 下载与使用

### 推荐方式：软件内自动下载

1. 打开「设置 → 语音识别」，选择「本地识别」。
2. 准备稳定网络，并预留至少 2GB 磁盘空间。
3. 导入一个 30-60 秒的短视频，点击开始识别。
4. 第一次识别会自动下载 `onnx-community/whisper-small` 的量化模型。
5. 软件先尝试国内镜像；镜像失败后自动切换到 Hugging Face 官方源。
6. 下载完成后模型永久保存在本机，后续识别不会重复下载。

首次下载耗时取决于网络速度。下载和初始化期间不要关闭软件。

### 查看下载状态和缓存位置

打开「设置 → 识别教程」：

- 查看是否检测到完整模型缓存。
- 查看模型文件数量和占用空间。
- 点击「打开模型目录」。
- 点击国内镜像或官方模型页检查网络是否能访问。

模型缓存在当前 Windows 用户的应用数据目录，不会因为软件重启而消失。

### 下载失败处理

1. 确认磁盘至少还有 2GB 空间。
2. 暂停占用网络的下载、网盘和视频程序。
3. 检查防火墙、代理软件是否拦截应用联网。
4. 分别尝试打开国内镜像页和 Hugging Face 官方模型页。
5. 关闭软件后，删除模型目录里明显未完成的临时文件，再重新识别。
6. 不要只下载单个 ONNX 文件；模型还需要 tokenizer、配置和预处理文件。

### 离线电脑使用

1. 在能联网的电脑安装相同版本 KBCut。
2. 完成一次本地识别，确保「识别教程」显示已检测到模型缓存。
3. 点击「打开模型目录」，复制整个模型目录。
4. 在离线电脑打开相同位置，将整个目录完整复制过去。
5. 重启软件并刷新模型状态。

## 二、在线 Whisper 配置与使用

### 服务商必须满足的条件

- 支持 OpenAI 兼容接口 `POST /v1/audio/transcriptions`。
- 支持文件上传。
- 最好支持 `verbose_json`、分句时间戳和词级时间戳。
- 有足够的单文件大小、请求频率和账户额度。

### 配置步骤

1. 在服务商控制台创建 API Key。
2. 打开「设置 → 语音识别」，选择「在线识别」。
3. API 地址填写服务根地址，例如 `https://api.openai.com`。
4. API Key 填写服务商生成的密钥。
5. 模型默认填写 `whisper-1`；第三方服务必须填写控制台提供的真实模型名称。
6. 先使用 30-60 秒短视频测试，再运行批量队列。

地址填写 `https://example.com` 或 `https://example.com/v1` 都可以，软件会统一请求 `/v1/audio/transcriptions`。

### 常见错误

| 错误 | 常见原因 | 处理方式 |
| --- | --- | --- |
| 401/403 | Key 无效、权限不足、余额不可用 | 重新生成 Key，检查账户额度和模型权限 |
| 404 | 地址或模型名称错误 | 对照服务商接口文档检查根地址和模型 ID |
| 413 | 音频超过单文件限制 | 使用限制更高的服务商，或等待后续分块上传功能 |
| 429 | 请求过快或额度受限 | 等待冷却，降低批量速度，检查套餐限制 |
| 5xx/超时 | 服务商异常或网络不稳定 | 稍后重试，或更换 ASR 服务商 |

## 三、怎么选择

| 场景 | 建议 |
| --- | --- |
| 大批量生产、要求速度和时间戳精度 | 在线识别 |
| 素材敏感、不希望上传音频 | 本地识别 |
| 网络不稳定但电脑配置尚可 | 本地识别 |
| 低配置电脑 | 在线识别 |
| 无 API 预算 | 本地识别 |

## 隐私说明

- 本地识别不上传音频。
- 在线识别会把提取后的音频上传到用户配置的 ASR 服务商。
- 使用在线服务前，应确认服务商的数据保存和隐私政策。
