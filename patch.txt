+ # 从零开始使用
+
+本指南假设你在一台**全新的 Windows 10/11 64 位电脑**上，没有任何 API、模型、FFmpeg 或 KBCut 历史。
+
+## 第一步：安装
+
+1. 打开 [Releases](https://github.com/cglyvip/kbcut/releases)，下载最新 `口播智剪-*-win-x64-setup.exe`。
+2. 双击安装，期间保持默认选项即可。
+3. 安装完成后启动「口播智剪」。
+
+安装包自带 FFmpeg / FFprobe（约 270MB 安装包），无需单独安装任何视频处理工具。
+
+## 第二步：选择语音识别方式
+
+打开软件后，点击右上角「设置」，切换到「语音识别」。
+
+你需要二选一：
+
+### 方式 A：在线识别（推荐）
+
+**优点**：速度快，时间戳精确
+**要求**：需要用户自己的 Whisper API
+
+1. 选择「在线识别」。
+2. 填写 API 地址（如 `https://api.openai.com`）。
+3. 填写 API Key（在服务商后台获取）。
+4. 模型名称（如 `whisper-1`）。
+5. 先用 30-60 秒短视频测试。
+
+### 方式 B：本地识别（无需 API）
+
+**优点**：免费、不上传音频
**要求**：首次需联网下载模型
+
+1. 选择「本地识别」。
+2. 准备稳定网络，确保至少 2GB 剩余磁盘空间。
+3. 导入视频并开始识别，软件会自动下载 Whisper 模型到本机。
+4. 第一次下载完就永久保存在用户数据目录，之后无需重下载。
+5. 如需了解离线复制等操作，点击「识别教程」查看详情。
+
+**建议**：识别小视频测试下载，下载成功后再跑大批量。
+
+## 第三步：配置大模型 API
+
+打开「设置 > 大模型 API」。
+
+模型重组视频结构依赖于 LLM。如果你用自己申请的 OpenAI 兼容 API：
+
+1. 点击「+ 添加候补 API」。
+2. 填写名称、URL、API Key、模型名称。
+3. 点击「测试」验证是否可用。
+4. 有多个 API 可以添加多个候补，若第一个失败会自动切第二个。
+
+如果你只有纯本机 LLM（如 LM Studio/Ollama），可以去「本地模型推荐」页，检测本地服务后一键填入。
+
+## 第四步：视频处理
+
+现在你已经有了 LLM + ASR 之一，可以处理视频。
+
+1. 点击「打开设置 > 导出偏好」，设定变体数、时长（建议 15-60 秒）。
+2. 返回主界面，选择批量模式（默认）。
+3. 选择输出目录，只需设置一次。
+4. 拖入视频，按拖入顺序排队。
+5. 点击「开始」。
+
+软件会逐条处理：视频 → 语音识别 → AI 重组 → 导出。AI 故障暂停，识别 / 导出失败继续下一条。完成一条后自动清空内存再处理下一条。
+
+## 第五步：检查导出结果
+
+导出完成后，点击「打开输出文件夹」获得 MP4 文件。
+导出为 1080P 清晰度，可保持原视频比例，字幕可开关。
+
+## 常见问题
+
+### 什么都不想做？
+
+1. 在 GitHub Releases 下载安装包（~270MB）。
+2. 获得一个 Whisper API 地址、API Key、模型名称。
+3. 获得一个大模型 API 地址、API Key、模型名称。
+4. 填入设置并启动。
+
+如果你还没有任何 API，建议使用线上开放中立的 Whisper/LM 服务（国内也常见），按上面的模板填写即可。
+
+### 本地识别下载不了？
+
+打开「设置 > 识别教程」，查看模型是否已下载完成。联网的机器第一次运行时会下载模型到本地用户目录，之后不用联网。
