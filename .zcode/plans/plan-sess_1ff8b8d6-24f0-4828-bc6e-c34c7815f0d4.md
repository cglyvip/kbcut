# 低优先级改进实施计划

## 任务 1：拆分 SettingsModal.tsx（910 行 → 多个子组件）

当前文件结构：
- 行 1-80: 接口/工具定义
- 行 82-258: 组件主体（状态 + 回调）
- 行 259-727: JSX（6 个 tab 内容）
- 行 729-909: styles 对象

**拆分方案：**

```
src/renderer/src/components/Settings/
├── SettingsModal.tsx          (主壳：modal/tabs/消息/footer，~150行)
├── tabs/
│   ├── LlmTab.tsx             (大模型 API tab)
│   ├── AsrTab.tsx             (语音识别 tab)
│   ├── AsrGuideTab.tsx        (识别教程 tab)
│   ├── ExportTab.tsx          (导出偏好 tab)
│   ├── LocalModelTab.tsx      (本地模型推荐 tab)
│   └── AboutTab.tsx           (关于 tab)
├── types.ts                   (AsrModelInfoView, LocalModelAdviceView 等接口)
├── styles.ts                  (共享 styles 对象)
└── utils.ts                   (formatBytes 等工具函数)
```

**设计原则：**
- 每个 Tab 组件接收必要的 store 数据 + 回调 props（或直接在内部使用 store hooks）
- `msg`/`err`/`setMsg`/`setErr` 通过 props 传入各 tab（因为底部统一显示）
- `openExternal`/`copyText` 提取为共享工具，通过 props 或 context 传递
- styles 分离为独立文件，tab 组件 import 使用

## 任务 2：添加 ESLint + Prettier 配置

当前状态：ESLint 和 Prettier **未安装**（devDependencies 中没有）。

**计划：**

1. 安装依赖：
   ```bash
   npm install -D eslint @eslint/js typescript-eslint eslint-plugin-react-hooks eslint-plugin-react-refresh prettier
   ```

2. 创建 `eslint.config.js`（ESLint 9 flat config）：
   - 继承 `@eslint/js` recommended
   - 继承 `typescript-eslint` recommended
   - 配置 react-hooks 和 react-refresh 插件
   - 自定义规则：`semi: ['error', 'never']`、`quotes: ['error', 'single']`
   - 忽略 `out/`、`dist/`、`node_modules/`

3. 创建 `.prettierrc`：
   ```json
   {
     "semi": false,
     "singleQuote": true,
     "jsxSingleQuote": false,
     "trailingComma": "none",
     "tabWidth": 2,
     "printWidth": 120
   }
   ```

4. 添加 npm scripts：
   ```json
   "lint": "eslint src/",
   "lint:fix": "eslint src/ --fix",
   "format": "prettier --write src/"
   ```

5. 创建 `.editorconfig`（基础编辑器一致性）

## 任务 5：减少 `any` 类型使用

当前统计：~97 处 `: any` + 5 处 `as any`

**重点目标文件（top 5）：**
| 文件 | `: any` 数 |
|------|------|
| ExportPanel.tsx | 10 |
| ipc/index.ts | 10 |
| variant-generator.ts | 8 |
| batch-checkpoint.ts | 8 |
| SettingsModal.tsx | 7 |

**策略：**
- `catch (e: any)` → `catch (e: unknown)` + 类型守卫（`e instanceof Error ? e.message : String(e)`）
- IPC handler 参数 → 定义具体接口类型
- `as LocalModelAdviceView` 等已知类型 → 用泛型或类型守卫替代 `as any`
- 对 FFmpeg/外部库返回值 → 定义最小接口
- **目标**：减少到 20 处以下，消除所有 `catch (e: any)` 模式
